Учебный проект второго курса по компьютерному зрению: самостоятельная реализация и исследование свёрточных нейронных сетей для выделения объектов из фона.

> Проект находится на этапе подготовки. Код, результаты обучения и примеры предсказаний будут добавляться по мере разработки.

## О проекте

Модель получает фотографию и предсказывает маску переднего плана — определяет, какие пиксели относятся к основному объекту, а какие к фону.

Для обучения используются разнородные изображения с готовыми масками. Постановка соответствует задаче **Salient Object Detection**: выделению главных, визуально значимых объектов сцены.

Основной исследовательский вопрос:

**Как архитектура CNN влияет на точность выделения объектов и восстановления их границ?**

## Цели

- Углубить понимание свёрточных нейронных сетей.
- Самостоятельно реализовать базовую сеть и U-Net на PyTorch.
- Разобраться в работе кодировщика, декодировщика и skip connections.
- Исследовать влияние глубины сети и аугментаций на качество сегментации.
- Сравнить модели в одинаковых условиях и проанализировать их ошибки.

## Датасет

В проекте используется [DUTS](https://saliencydetection.net/duts/) — датасет для выделения визуально значимых объектов с разметкой на уровне пикселей.

| Часть | Количество изображений | Назначение |
| --- | ---: | --- |
| DUTS-TR | 10 553 | Обучение и выделение валидационной выборки |
| DUTS-TE | 5 019 | Итоговая оценка качества |

Каждый пример представляет собой пару: **изображение и маска переднего плана**.

Валидационная выборка будет выделена из DUTS-TR и зафиксирована для всех экспериментов. DUTS-TE будет использоваться для итоговой оценки после выбора настроек по валидации.

Изображения и разметка доступны на официальной странице датасета. При их использовании необходимо учитывать условия авторов и ссылаться на исходную публикацию.

## Планируемые модели

| Модель | Устройство | Роль |
| --- | --- | --- |
| Базовая CNN | Кодировщик и декодировщик без связей между соответствующими уровнями | Отправная точка для сравнения |
| U-Net | Кодировщик и декодировщик со skip connections | Исследование пользы передачи пространственных признаков |

## Эксперименты

Планируется проверить:

1. **Skip connections** — как передача признаков между уровнями влияет на точность масок.
2. **Глубину сети** — как изменение числа уровней влияет на качество и переобучение.
3. **Аугментации** — насколько преобразования обучающих примеров помогают обобщению.

В каждом эксперименте будет изменяться один исследуемый фактор. Остальные условия обучения и оценки будут фиксироваться. Число параметров моделей будет учитываться при интерпретации результатов.

## Оценка качества

Основные метрики для переднего плана:

- **IoU** — отношение площади пересечения предсказанной и эталонной масок к площади их объединения.
- **Dice** — степень совпадения масок с учётом размеров выделенных областей.

Дополнительно будут анализироваться:

- кривые обучения и валидации;
- ошибки на сложном фоне;
- неточности на границах объектов;
- примеры успешных и неудачных предсказаний.

Результаты будут представлены в сравнительной таблице и визуализациях: **исходное изображение, эталонная маска и предсказание модели**.
